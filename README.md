## Overview

ChowPhaser is an open-source phaser effect with analog circuit modeling inspired by the Uni-Vibe, featuring two modulation modes, a feedback network, and a skewed feedback path for rich phasing character.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ChowPhaser** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Uni-Vibe Model** | Circuit-based emulation of Uni-Vibe phaser with bulb and LDR model |
| **Two Mod Modes** | Standard LFO and envelope follower modulation modes |
| **Feedback Network** | Configurable positive/negative feedback for deep notch character |
| **Drive Stage** | Input drive adds harmonics before the phaser network |
